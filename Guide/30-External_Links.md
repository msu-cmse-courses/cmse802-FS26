# Resources

This page contains some links that other student's have found useful.  


# Useful tools to help you get started. 
* [Bash Dungeon](https://github.com/wolandark/bash-dungeon) - An cleaver folder based game to learn and practice navigating your filesystem using a BASH command prompt (Unix).  
* [Unix Command Cheat Sheat](https://upload.wikimedia.org/wikipedia/commons/7/79/Unix_command_cheatsheet.pdf) - A single pdf designed to help students remember common command line commands (ex. ls, cd, pwd, etc)
* [Oh My Git](https://ohmygit.org/) - An open source game about learning Git!
* [Git Branching Tutorial](https://learngitbranching.js.org/) - Interactive tutorial to help you learn branching. 
* [VI Cheat Sheet](https://ryanstutorials.net/linuxtutorial/cheatsheetvi.php) - VI (or VIM) is a text editor that is avaliable on almost all (non-windows) systems.  It is powerful but complex tool with a lot of (non-obvious) commands.  Here is a cheatsheet to help you remember the commands.
