# Analytical Modeling Project

In this assignment, you will focus on analytical modeling workflows: representing systems with equations, implementing those models in code, and evaluating results with clear, reproducible software practices.

This project is expected to span approximately four class periods (about two weeks).

Most daily work for this assignment will happen in the project repository:

- Repository: [Analytical Modeling Project Repository](https://github.com/USERNAME/analytical-modeling)
