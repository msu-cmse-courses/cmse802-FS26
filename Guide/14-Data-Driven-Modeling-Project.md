# Data-Driven Modeling Project

In this assignment, you will apply data-driven modeling methods to support research questions, including data preparation, model training or fitting, and reproducible evaluation of model performance.

This project is expected to span approximately four class periods (about two weeks).

Most daily work for this assignment will happen in the project repository:

- Repository: [Data-Driven Modeling Project Repository](https://github.com/colbrydicon/data-driven-modeling)

Use the repository workflow and documentation for the detailed class-by-class tasks.
