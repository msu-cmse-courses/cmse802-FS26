# Modeling Intro Project

This first major assignment helps you establish a clear, working project baseline. You will set up your repository workflow, confirm that your environment runs, and begin organizing your modeling work so it can be shared, reviewed, and extended.

This project is expected to span approximately four class periods (about two weeks).

Most daily work for this assignment will happen in the project repository:

- Repository: [Modeling Intro Project Repository](https://github.com/colbrydi/modeling_intro)

Use the repository README, issues, and assignment prompts as the source of day-to-day instructions.
