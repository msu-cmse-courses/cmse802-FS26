# Milestone 4: Documentation and Reproducibility Pass

## Due Date

This milestone is due on {{ page.date | date: "%B %d, %Y" }}.

## What to Submit

Submit a documentation and reproducibility pass that makes the project easier to understand and reuse.

### Documentation improvements

Your submission should include:

- an improved README that explains the purpose, workflow, and main outputs of the project
- clear installation or environment instructions
- usage examples, examples of expected output, or short walkthroughs
- docstrings, comments, or other explanatory notes for core functions or notebooks

### Reproducibility notes

Include brief information about:

- how someone can recreate the environment or dependencies
- how to run the main workflow from a fresh clone
- any important assumptions or steps that are easy to miss

## Expectations

This milestone is meant to make the project understandable to someone other than the original author. The goal is not to produce perfect documentation, but to make the project significantly more usable and reproducible.

## Submission Notes

Submit:

- a link to the repository
- a short summary of the documentation and reproducibility improvements
- any key instructions or examples a reader should review first
