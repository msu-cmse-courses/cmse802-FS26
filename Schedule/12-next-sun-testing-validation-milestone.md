# Milestone 3: Testing and Validation Baseline

## Due Date

This milestone is due on {{ page.date | date: "%B %d, %Y" }}.

## What to Submit

Submit an initial testing and validation baseline for your project.

### Tests and validation

Your submission should include:

- at least one meaningful test or validation example for a core part of the workflow
- clear evidence that the software behaves as expected for the main use case
- notes about assumptions, limitations, or known edge cases
- a brief explanation of how you will expand testing in the next phase

### Supporting materials

You may also include:

- example input and output files
- a short validation script or notebook
- notes on how you handle failures or unexpected results

## Expectations

This milestone is about building confidence in the software rather than achieving full coverage. Your goal is to show that the project now has a credible foundation for checking correctness and documenting how it should behave.

## Submission Notes

Submit:

- a link to the repository
- a summary of the tests or validation steps you added
- a brief note on what remains untested or still needs attention
