### Learning Goals

By the end of this class, you should be able to:

- Evaluate whether a simulation result is credible in light of its assumptions.
- Distinguish physical behavior from artifacts of implementation or approximation.
- Describe how testing, documentation, and reproducible execution support model trust.

## In-Class Focus

This final physical-modeling session brings the unit together. We will use the repository to review the full workflow: physical system, assumptions, computational rules, simulation, observation, interpretation, and validation.

Use the repository as the primary working reference:

- Repository: <https://github.com/colbrydi/physical-modeling>
- Catch-up targets: `01_SIR_Intro.ipynb`, `02-Wave_Equaiton.ipynb`, and `03-Finite_Element_Analysis.ipynb`
- Supporting code: `wave2d.py`, `run_wave2d.py`, and `tests/test_wave2d.py`

If the core notebook work is complete, use the remaining time to improve the reproducibility of a simulation workflow or to connect physical-modeling ideas to your project domain.
