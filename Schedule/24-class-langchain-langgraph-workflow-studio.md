# LangChain and LangGraph - Day 1

Repository: <https://github.com/maryambrj/langchain-langgraph-tutorials>

This two-day workflow introduces LangChain and LangGraph using Google Colab. We will run the [LangChain + LangGraph tutorial](https://github.com/maryambrj/langchain-langgraph-tutorials) in order, beginning with a small open Hugging Face model. The TA may also demonstrate larger or more capable models so we can compare their behavior, resource needs, and limitations.

## Agenda (80 minutes)

1. 10 min - Check-in, tutorial overview, and Google Colab workflow
2. 15 min - Create a Colab copy, install dependencies, and load a small Hugging Face model
3. 20 min - Guided work: basic LLM calls, multi-agent collaboration, and LCEL chains
4. 20 min - Guided work: compare fixed chains with routed LangGraph workflows
5. 10 min - Compare model behavior and discuss resource, reproducibility, and trust tradeoffs
6. 5 min - Record questions and prepare to continue the tutorial

## Learning Goals

By the end of this class, you should be able to:

- create and run a Google Colab copy of a research-computing tutorial using a Hugging Face model; and
- explain how prompts, models, chains, and routed graphs organize an LLM workflow.

## In-Class Focus

Use the tutorial repository as the primary working reference:

- Repository: <https://github.com/maryambrj/langchain-langgraph-tutorials>
- Notebook: `workshop_LangChain.ipynb`
- Platform: Google Colab

Today we establish the Colab workflow and complete the tutorial sections on setup, basic usage, multi-agent collaboration, LangChain Expression Language, and routing versus chaining. As you work, notice which steps are fixed, which can branch, and how changing the model affects the output.

Do not enter API keys, restricted research data, participant information, or other sensitive material into the notebook. Use Colab Secrets for any required Hugging Face token; never place a token in a notebook cell or commit it to a repository.

## Before Next Class

- Record the Hugging Face model name and Colab runtime you used.
- Bring your Colab copy and notes to continue with tools, RAG, reflection, and human-in-the-loop workflows.
