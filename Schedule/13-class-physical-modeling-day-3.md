# Physical Modeling - Day 3

Repository: <https://github.com/colbrydi/physical-modeling>

## Agenda (80 minutes)

1. 10 min - Check-in and review of the wave-model workflow
2. 20 min - Discuss finite-element tools, model choice, and reusable software
3. 35 min - Guided work in `03-Finite_Element_Analysis.ipynb` and the wave-model scripts
4. 15 min - Review testing and execution questions

### Learning Goals

By the end of this class, you should be able to:

- Explain why model choice and discretization matter for physical simulations.
- Connect a notebook prototype to reusable scripts and basic tests.
- Identify what evidence is needed to support a simulation result.

## In-Class Focus

This session connects physical-modeling methods to research software practice. We will consider how a prototype becomes a reusable simulation that can be tested, documented, and run beyond the notebook environment.

Use the repository as the primary working reference:

- Repository: <https://github.com/colbrydi/physical-modeling>
- Notebook: `03-Finite_Element_Analysis.ipynb`
- Supporting code: `wave2d.py`, `run_wave2d.py`, and `tests/test_wave2d.py`

Focus on the connection between the modeled system, the software structure, and the checks that make the workflow more trustworthy.

## Before Next Class

- Bring one question about interpreting or trusting a simulation result.
