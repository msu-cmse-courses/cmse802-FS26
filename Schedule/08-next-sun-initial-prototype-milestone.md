# Milestone 2: Initial Prototype and Working Workflow

## Due Date

## What to Submit

Submit a first working prototype that demonstrates the main capability of your project.

### Prototype

Your submission should include:

- a working implementation of the core feature, workflow, or analysis pipeline
- a clear example of the output or result your software produces
- initial setup or installation instructions that allow someone else to run it
- a simple repository structure that shows the project is organized for continued development

### Evidence of progress

Include brief notes that explain:

- what the prototype demonstrates
- what remains to be improved
- how you will test or validate the next phase of the work

## Expectations

This milestone is meant to show that the project has moved beyond planning into an early, testable implementation. The prototype does not need to be polished, but it should be credible, meaningful, and useful for further development.

## Submission Notes

Submit:

- a link to the repository
- a brief summary of the prototype and its current capabilities
