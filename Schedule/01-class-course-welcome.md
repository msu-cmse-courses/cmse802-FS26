### Learning Goals

By the end of this class, you should be able to:

- Explain the main purpose of CMSE 802.
- Identify the course expectations and weekly workflow.
- Set up a playground repository using the course template.
- Name one research direction you may want to use in the course.

## 1. Welcome

CMSE 802 helps you build better research software. You'll learn software engineering practices, explore computational tools and modeling approaches, and discover techniques you can adapt to your own research.

### GitHub, GitLab, and Choice

You do not need to create a GitHub account for this course.

Instead, you may choose the platform that best fits your situation:

| Platform | Strengths | Notes |
| --- | --- | --- |
| GitHub | Familiar to many students, easy template sharing, strong public collaboration support | Useful if you want a public-facing portfolio or already have an account |
| MSU GitLab | Good choice for MSU-supported work, private collaboration, and class-specific repositories | A strong option if you want to keep course work separate from a public profile |

Use whichever platform helps you work clearly and consistently. The class will support either option.

## Playground Repository Activity

Your first hands-on task is to create a playground repository using the course template. This is a practice space, not your final project repository.

Suggested first steps:

1. Open the course template.
2. Create or clone a playground repository.
3. Make one small markdown edit.
4. Save and commit that change.
5. Note any questions or problems you want help with next time.
