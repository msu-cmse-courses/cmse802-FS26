# Milestone 5: Release Candidate and Handoff Package

## Due Date

This milestone is due on {{ page.date | date: "%B %d, %Y" }}.

## What to Submit

Submit a release candidate version of your project that is close to final presentation quality.

### Release candidate materials

Your submission should include:

- a cleaned-up and organized repository structure
- a feature-complete version of the main project workflow
- passing tests or other validation evidence
- polished documentation and usage instructions
- a brief summary of what has been improved since the previous milestone

### Handoff readiness

Include a short note that explains:

- what is ready for evaluation or demonstration
- what remains as a lower-priority improvement
- how someone else could continue the work if needed

## Expectations

This milestone is intended to show that the project is approaching a stable and presentable state. The focus is on polish, clarity, and making the work easy to evaluate and hand off.

## Submission Notes

Submit:

- a link to the repository
- a short summary of the release candidate state
- a brief note on the most important remaining improvement areas
