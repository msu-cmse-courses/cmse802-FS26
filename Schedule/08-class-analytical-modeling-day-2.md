### Learning Goals

By the end of this class, you should be able to:

- Describe the role of symbolic tools in exploring analytical models.
- Interpret parameter sensitivity and model behavior using computation.
- Use the repository notebooks to explore model structure and assumptions.
- Identify places where a model may be easy to interpret but difficult to trust.

## In-Class Focus

This class continues the analytical-modeling workflow by moving from model definition to model interpretation. We will focus on understanding what parameters do, how solutions behave, and how a model can be analyzed both symbolically and numerically.

Use the repository as the main working reference:

- Repository: <https://github.com/colbrydi/analytical-modeling>
- Notebook sequence: Part 1 and Part 2

The emphasis is on reasoning, not just producing code output. As you work, ask:

- What does the model actually represent?
- Which parameter changes the behavior most?
- What is the difference between a symbolic answer and a numerical observation?
- What does model behavior suggest about the assumptions behind the model?
