## Agenda (80 minutes)

### Learning Goals

By the end of this class, you should be able to:

- Distinguish regression, classification, and clustering using the same dataset.
- Use evidence from your own experiments to judge whether a dataset is large enough for a model.

## In-Class Focus

Statistics describe; machine learning predicts. Today we use scikit-learn on one small dataset to ask three different questions, compare each model against a simple baseline, and watch what happens when a model sees too few observations or too many features.

Use the repository as the primary working reference:

- Repository: <https://github.com/colbrydi/data_driven_modeling>
- Notebook: `Assignment_Instructions_Part_2.ipynb`

The notebook gives you a working scaffold and expects you to look things up in the scikit-learn documentation. As you work, consider whether the model beats the baseline, how you know you are not fooling yourself, and whether machine learning was necessary at all.
