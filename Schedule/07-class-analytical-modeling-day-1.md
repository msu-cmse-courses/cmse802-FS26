### Learning Goals

By the end of this class, you should be able to:

- Explain the purpose of the analytical-modeling repository and how it fits the course.

- Discuss how symbolic and numerical tools help us reason about model behavior.
- Prepare to work through the first notebook in a reproducible, shared workflow.

## In-Class Focus

This first analytical-modeling day introduces the repository and the key idea behind the unit: analytical models are useful not just as equations on a page, but as computational tools that help us explore, test, and interpret scientific behavior.

We will work through the repository in order:

- Repository: <https://github.com/colbrydi/analytical-modeling>
- Primary guide: README.md
- First notebook: Assignment_Instructions_Part_1.ipynb

Most of the class will be a guided walkthrough and discussion. The goal is not to memorize formulas but to build a shared understanding of how analytical components fit into larger modeling workflows.

As you work, keep track of:

- what the analytical model is supposed to describe,
- which parameters matter most,
- what questions are easiest to answer symbolically versus numerically,
- how the model connects to your own project domain.
