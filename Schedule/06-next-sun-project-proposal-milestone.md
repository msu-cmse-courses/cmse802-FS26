# Milestone 1: Project Proposal and Initial Git Repository

## Due Date

This milestone is due on {{ page.date | date: "%B %d, %Y" }}.

## What to Submit

Submit a short project proposal and an initial repository for your course project.

### Project proposal

Your proposal should include:

- a clear research question or software problem you want to address
- the main model components involved, such as analytical, physical, or data-driven elements
- a realistic software goal for the semester
- a planned timeline for the first phase of the work
- a short plan for how you will test or validate the work
- a metric for success, meaning a concrete way you will know your software goals have been met

### Initial Git repository

Your repository should include:

- a README that explains the project purpose and basic workflow
- a simple project structure that can grow over the semester
- at least one initial commit
- a visible default branch or repository structure that shows the work has started
- instructor read access to the repository before submission

## Expectations

This is a proposal and scaffold milestone, not a finished implementation. The goal is to make the project concrete enough that you can begin building with a clear direction and a shared software foundation.

## Submission Notes

Submit:

- a link to the repository
- a short summary of your proposal
- a note about your first planned next step
